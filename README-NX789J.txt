RedMagic Tile Studio 1.0
=======================

适配：红魔 NX789J / REDMAGIC OS 11 / Android 16（SDK 36）。
框架：支持 libxposed API 102 的 Vector；作用域仅系统界面 com.android.systemui。
对外版本为 1.0，内部 versionCode 为 5，可覆盖此前 versionCode=4 的测试版。

本次修复
--------
- 新增“版本与更新”卡片，提供 GitHub 发布页和项目主页入口；无浏览器时可复制链接。
- 正式构建要求 repository.properties 配置真实更新仓库。
- 诊断按内部版本判断 SystemUI 是否加载旧代码，支持显示版本仍为 1.0 的更新。
- 当前运行错误与“已恢复历史”分别记录。配置读取恢复后，旧 Unknown authority
  不再显示在当前错误中；其他尚未恢复的错误仍会保留。
- 配置服务暂时不可用时，最多自动重试 8 次（逐步延长间隔，总等待 27.5 秒）。
  首次尚无配置时保持关闭；已有成功配置时保留该配置，恢复后重新同步。
- 历史记录合并相同失败，最多保留最近 8 项已恢复事件，包含发生/恢复时间。
- 诊断支持查看历史与复制完整信息，区分未应答、同步待恢复和仍加载旧版。
- 程序显示、模块报告和安装包版本统一读取 version.properties。
- 正式发布构建必须使用工程目录外的独立私钥，禁止回退到公开测试签名。

已有功能
--------
- 竖屏 3-7 列，横屏 3-8 列；图标尺寸 65%-110%。
- 圆形磁贴左右可见边缘对齐上方原生卡片，中间各列均匀排列。
- 最小横向间距、纵向间距、文字大小和名称开关。
- 不修改顶部宽卡片、音乐、亮度、音量与系统实际分区。
- 原厂布局恢复、设备加密配置存储、跨进程实时配置更新。

安装与使用
----------
1. 覆盖安装 RedMagicTileStudio-NX789J-v1.0.apk，本次沿用此前 APK 的测试签名。
2. Vector 中启用“红魔磁贴布局”，作用域勾选“系统界面 / SystemUI”。
3. 重启手机，确保 SystemUI 加载新代码。
4. 打开模块，启用优化；展开控制中心后返回模块检测。
5. 正常时应显示模块版本 1.0、配置读取成功、实际列数符合设置、当前运行错误“无”。
   已恢复记录可能大于 0，这些记录可通过“历史记录”查看。

回退
----
点击“一键恢复原厂布局”关闭优化；无法进入程序时，在 Vector 停用模块后重启。

编译
----
Termux 中已有 Java 21、Gradle、ARM64 aapt2、Android SDK 36 时：
 bash build-termux.sh
SDK 许可需由运行者自行确认。也可使用已配置的 Termux Studio。

独立构建（需要现有 SDK 工具与 Eclipse ECJ，不自动下载工具或接受许可）：
 python3 tools/build-standalone.py --android-jar /path/to/android.jar \
   --build-tools /path/to/build-tools --ecj /path/to/ecj.jar \
   --output /path/to/RedMagicTileStudio-NX789J-v1.0.apk

正式发布的签名与版本流程见 PUBLISHING.txt。
公开仓库和发布源码包不包含任何签名密钥库。独立构建会自动生成本地测试密钥；
Gradle 默认使用 Android 本地调试签名。自行编译包通常不能覆盖发布页的测试 APK。
发布者保留本地原签名用于后续覆盖升级；正式发行需要单独保存的外部私钥。
